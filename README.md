Midnight Fridge Roast — a one-line roast of a smart fridge that refuses to open after midnight. The graded entrypoint `main.py` uses only the Python standard library: it writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` when set).

## Run it

```sh
python3 main.py
```
